# KJV Bible
Offline King James Bible for Android: easy reading (text size, serif/sans, light/sepia/dark, red letters), fast search (words, "phrases", prefix*, or a reference like Ps 23), favorites, highlights and notes. Text: 1769 Cambridge KJV from eBible.org (public domain in the US).
Build: GitHub Actions > Build Android app > download the APK artifact.
